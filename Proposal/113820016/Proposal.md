# Game Introduction

本專案旨在開發一款經典的 2D 橫向捲軸平台遊戲，核心機制參考《超級瑪利歐》。玩家將操作角色在具備重力物理的環境中進行跳躍、移動與探索。專案需實作嚴謹的碰撞偵測與角色狀態管理，並透過互動方塊獲取資源。

參考影片：https://www.youtube.com/watch?v=2on4G_hb-_c

# Development timeline

- **Week 2：專案初始化與素材整備**
  - [ ] 蒐集遊戲的素材（角色、磚塊、背景、UI）
  - [ ] 建立專案骨架與基礎算繪視窗

- **Week 3：地圖載入機制與基礎物理基礎**
  - [ ] 實作 CSV 格式之地圖解析器（MapManager）
  - [ ] 設計基礎物理引擎（引入全域重力 Gravity 與下墜速度演算）
  - [ ] **[架構預防]** 定義速度 (Velocity) 繼承介面，為未來的動態平台與龜殼反彈預留物理基礎

- **Week 4：角色控制與視圖矩陣 (Camera)**
  - [ ] 設計角色移動（左右加速、摩擦力減速）
  - [ ] 設計角色跳躍（拋物線計算與落地判定）
  - [ ] 設計橫向捲軸攝影機（Camera 跟隨、限制不可後退邊界）

- **Week 5：碰撞系統架構規範與基礎互動**
  - [ ] **[核心重構提前]** 確立碰撞系統介面設計規範，定義 CollisionManager 與 Entity 的職責分配（避免後期重構風險）
  - [ ] 實作角色與靜態地形（地板、磚塊）的 AABB 碰撞阻擋
  - [ ] 實作由下而上頂撞方塊的物理反饋與彈跳動畫

- **Week 6：道具系統與動態生成**
  - [ ] 實作問號方塊受擊後的道具生成邏輯
  - [ ] 實作道具（蘑菇、無敵星）的專屬移動與物理彈跳邏輯

- **Week 7：角色狀態機 (State Machine) 與獨立驗證**

- **Week 8：敵人實體與區域喚醒機制**

- **Week 9：戰鬥、傷害判定與核心 MVP 達成**
